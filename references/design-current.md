# 최신 확정 디자인 규칙 / 2026-10-28

가장 최근 사용자 지시를 우선한다. 기준 파일은 `assets/master-current.html`이며 VOL.030 및 VOL.031 대화 수정사항을 반영했다. `master-vol019.html`은 이전 호출의 호환 경로로 동일한 바이트를 제공한다. VOL.019의 과거 디자인으로 되돌리지 않는다.

- 680px 테이블 캔버스, 현재 헤더 색상과 흰 글자 및 SNS 아이콘, 푸터, 섹션 간격을 유지한다. 헤더의 국내 재단 공익 설명 문구와 TODAY IN NUMBERS를 다시 넣지 않는다.
- 여성의 삶과 아름다움의 의미는 상단 2열이며 이미지를 넣지 않는다. 다음은 인재육성 및 학술연구, 문화예술, 청년지원, FROM NEWS TO INSIGHT, EDITOR’S PICKS, 美리보기, 의견 CTA, 지난 뉴스레터 링크 순서다. 기타 공익 카테고리를 자동 추가하지 않는다.
- 기사 제목, 한줄 리드, 이미지/요약 2열, 출처와 사진 크레딧, WHY IT MATTERS 배치를 유지한다.
- 세 본문 기사 이미지는 실제 파일 및 HTML width=278 height=150으로 통일한다. 포스터는 사용자 지시에 따라 확대 후 크롭할 수 있다. 이미지마다 원문과의 대응과 출처를 남긴다.
- 요약 본문 td에는 valign="middle" 및 인라인 vertical-align:middle을 함께 지정한다. 이미지와 본문 사이 간격은 20px이다. 모바일에서는 기존 한 열 쌓기를 유지한다.
- 요약은 보통 130~170자 안팎에서 원문 사실을 충실히 전달한다. 글자 수만 강제하지 말고 실제 렌더링으로 이미지와 본문 높이를 비교한다. 빈칸을 채우려고 확인되지 않은 설명을 만들지 않는다.
- 기사 출처 링크와 도서 소개 링크는 인라인 font-weight:700으로 굵게 표시한다. 출처 글꼴과 크기를 통일한다.
- EDITOR’S PICKS 이미지는 230x189px, 美리보기 책 표지는 118x157px이다. 이 두 이미지를 기사 사진 규격으로 통일하지 않는다.
- 사용자 제공 사진도 원본으로 사용할 수 있다. 이미지가 확보되지 않으면 다른 기사 사진으로 대체하지 않고 상태를 명시한다.
- 美리보기는 아시아의 美 공식 도서를 검증하고 매 호 책, 표지, 저자, 권수, 질문, 해설, 링크를 함께 교체한다. 마스터의 산수화가 만든 세계를 자동 재사용하지 않는다.
- 새 호에는 예시 기사와 이미지, 날짜, VOL 번호를 모두 교체한다. 링크, 이미지 SHA-256과 본문을 이전 호와 대조한다. 마스터는 형식 예시이지 다음 호 선정 목록이 아니다.
- 실제 발송 검증과 HTML 검사를 구분한다. Outlook 실수신과 PC/모바일 화면을 확인하지 않았다면 미검증으로 기록한다.
- GitHub 파일 생성/업데이트가 요청되면 연결된 커넥터로 저장소와 브랜치를 확인하고 직접 기록한다. 사용자 PC 다운로드 후 업로드를 기본 단계로 요구하지 않는다. 기사 수집과 사진 가공은 각각 수집기와 편집 단계로 분리한다.
- 지난 뉴스레터 등록 요청 시 목록 메타데이터와 실제 HTML을 함께 갱신하고 연결을 검증한다. 제작만으로 실제 발송 이력을 생성하지 않는다.
